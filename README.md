# Medical Directory & Healthcare Portal

A production-ready, SEO-optimized, bilingual (English & Gujarati) medical web portal built for **Dr. Nasir Salar (Orthopedic & Spine Surgeon)** and **Unity Pathology Laboratory** in Sarkhej & Makarba, Ahmedabad.

## 🚀 Quick Start

```bash
# Install dependencies (already installed)
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portal.

## 📋 Features & Status

* **Static Search Directory (`/`):** Real-time client-side search across doctors, labs, procedures, and tests in English and Gujarati.
* **Dr. Nasir Salar Profile (`/orthopedic`):** Focused on Spine Surgery, MIS, and Endoscopic Spine procedures with verified education & training credentials.
* **Unity Pathology Lab Profile (`/pathology`):** 5.0 Google rating (60 reviews), interactive test directory, and sample collection inquiries.
* **Bilingual Switcher:** Header toggle for instant English / ગુજરાતી translation.
* **Direct Actions:** 1-tap WhatsApp consultation and direct phone call links.
* **SEO Optimized:** Google Schema.org JSON-LD, sitemap.xml, robots.txt, and local search metadata.
